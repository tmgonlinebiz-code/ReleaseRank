# ReleaseRank

A web application that compares multiple uploaded MP3 or WAV files and determines which version has the highest probability of success on YouTube and Spotify.

## Project Structure

```
ReleaseRank/
├── frontend/          # React + TypeScript application
├── backend/           # Python FastAPI application
├── docker-compose.yml # Docker orchestration
└── README.md          # This file
```

## Features

- Upload multiple audio files (MP3, WAV)
- Compare audio files for platform potential
- YouTube and Spotify success prediction
- Clean, intuitive UI

## Technology Stack

### Frontend
- React 18+
- TypeScript
- Vite
- TailwindCSS
- Axios

### Backend
- Python 3.11+
- FastAPI
- Pydantic
